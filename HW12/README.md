# HW12 / Traffic Sign Classification (Jupyter Version)

## Structure

```text
HW12/
├── data/
│   └── subset_homework/
├── homework/
│   └── Homework.ipynb
├── results/
├── README.md
└── requirements.txt
```

## How to run

1. Put your dataset into `data/subset_homework`
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open Jupyter Lab:
   ```bash
   jupyter lab
   ```
4. Open `homework/Homework.ipynb`
5. Run all cells

## Output files
The notebook saves results to `results/`:
- `samples.png`
- `class_distribution.png`
- `confusion_matrix.png`
